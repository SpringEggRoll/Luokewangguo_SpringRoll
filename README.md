# Luokewangguo_SpringRoll
AI生成网页进行相对较优的无限制网络计算，不需要提前锁定具体精灵，可以在考虑部分稀有精灵（如鸭吉吉，上岸蛙等）或非异色炫彩精灵的情况下计算异色网络

项目源代码地址：https://github.com/SpringEggRoll/Luokewangguo_SpringRoll/tree/main

部署网址：

【数据管理】使用内置数据即可，如果想上传自己的蛋组，上传含有组别和精灵名称的表格文件即可

【孵化参数】

（1）选择父本和母本数量，二者之和的最大值为10

**（2）指定母本和父本（可以不输入）：输入精灵名称，用逗号隔开。由于内置精灵仅使用最高形态或多形态中的其中一种形态，使用前可以在页面底部“内置精灵名录”中查找，以防输入的精灵信息不存在**

（3）指定期望的异色父母本数（可以不输入）

**（4）排除精灵：在生成结果之前可以填写自己没有的精灵进行排除计算；结果网络中可能有缺失连接的精灵，填写然后再次生成即可；此外，如果生成网络中存在单一连接的，可以将任一父母本排除然后再计算，可能会出现更优的网络**

（5）网络计算默认使用不重复的精灵进行网络计算，因此如果有重复精灵请输入指定母本和父本进行计算
